A static code analysis tool that integrates an AST-based dead code detector, a SQLite-backed symbol table for scope analysis, and an async concurrency tester for performance evaluation. The tool is modular and designed for production-grade CLI usage. Each component is separated into its own module, ensuring clear and maintainable code. The CLI interface leverages Rich for a rich terminal experience, while the core logic is robust and efficient. Comprehensive test coverage is provided through pytest and pytest-asyncio to ensure reliability and accuracy.
